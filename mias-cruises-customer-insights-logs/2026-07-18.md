# 2026-07-18 Log

## 项目背景

7 月 18 日的工作从 dashboard 内容优化转向产品体验升级。用户希望 dashboard 不只是静态报告，还能在读报告时直接提问。因此当天重点是 report-inspired UI、floating chat assistant、本地 RAG-like retrieval 和双语回答。

同时，PRD 补充了长期产品架构：平台未来应成为持续学习的 Voice of Customer Intelligence system，而不是一次性分析页。

## 当天目标

1. 让界面更接近 Mia's Cruises-style business report，但仍保留 SaaS 产品交互。
2. 在不破坏主 dashboard 的前提下加入 floating report assistant。
3. 让 assistant 能基于当前 dashboard evidence 回答，而不是固定 mock response。
4. 支持 English-first + input-language summary 的双语输出。
5. 修复浏览器缓存导致 Update Log 不刷新的问题。

## 测试数据与验证

当天没有生成新的 Excel 测试表，但把 dashboard 当前数据变成了 assistant 的检索语料：

- 公开 evidence snapshot 继续来自 `app/data.js`。
- Chat fallback 会返回：
  - English answer。
  - Top evidence。
  - Based on sources。
  - Translation summary。
- Chinese input 会得到 English-first answer + Chinese summary。
- English input 不应额外生成不相关第三语言摘要。

PRD / 架构验证重点：

- Evidence Knowledge Base：未来存 raw customer evidence，包括 Trustpilot、Reddit、Google Play、Apple App Store、Company News、Future Survey Data。
- Insight Knowledge Base：未来存 AI-generated business knowledge，包括 insights、root causes、recommendations、confidence 和 supporting evidence IDs。
- Evidence Retrieval Engine：支持 cross-source retrieval、competitor retrieval、historical insight retrieval。
- Explainable AI requirement：每个 AI conclusion 都要能回答证据来源、数据源和历史复现情况。

已知浏览器验证结论：

- Dashboard 可以初始化。
- Update Log 最新条目能在刷新后显示在顶部。
- Chat assistant 能打开、关闭、输入和发送。
- 本地 fallback assistant 能基于 dashboard evidence 返回 source-based answer。
- 中文问题能得到 English answer 和中文 summary。
