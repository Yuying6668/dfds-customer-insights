## 实现内容

- `server.py`：本地 Python backend，负责 frontend serving、`/api/chat`、`/api/health`、schema init、seed import、RAG retrieval、DeepSeek proxy 和 chat history。
- `db/schema.sql`：定义核心数据库结构。
- `data/seed.json`：由当前 `app/data/index.mjs` 导出的 public evidence snapshot。
- `work/export_seed_json.mjs`：后续 dashboard data 更新后可重新生成 seed。
- `work/build_dfds_rag_validation_excel.mjs`：生成 RAG validation workbook。
- `work/split_data_modules.mjs`：一次性/维护用数据拆分脚本，现在也读取新的 `app/data/index.mjs`。
- `backend/requirements.txt`：backend Python dependencies。
- `LOCAL_PGVECTOR_SETUP.md`：macOS PostgreSQL 17 + pgvector 本地运行说明。
- `Dockerfile`、`docker-compose.yml`、`.dockerignore`：保留 Docker fallback。
- `.env.example`：示例使用本地 `DATABASE_URL`，真实 key 只应在 ignored `.env` 或 shell env。
- `app/app.js`：现在是小型 frontend bootstrap，只负责导入模块、初始化页面渲染和绑定事件。
- `app/index.html`：改为 `type="module"` 加载 `app/app.js`，并更新 cache-busting script version。
- `app/styles.css`：chat supporting evidence cards 的前端展示样式。
- `app/index.html`、`app/styles.css`、`app/scripts/features/chat-assistant.mjs`：优化 chat assistant 的入口、标题、关闭按钮和可见说明文字，让收起态更商业、更简洁。
- `app/data/*.mjs`：按业务领域拆分公开数据，包括 routes、source coverage、app reviews、Google reviews、customer insights、competitors、recommendations 和 update log。
- `app/scripts/core/*.mjs`：DOM helper 和 UI state helper。
- `app/scripts/features/*.mjs`：页面渲染和交互模块，包括 overview、customer voice、app reviews、competitors、recommendations、sources、update log、export brief、navigation、chat assistant。
- `app/scripts/services/*.mjs`：local knowledge base、dashboard context、chat API、session ID。
- `app/scripts/utils/*.mjs`：格式化、评分解析、语言检测、HTML escaping 和 query tokenization。
